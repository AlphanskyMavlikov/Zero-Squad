# Умный подбор подрядчиков (#79-lite)

Готовое приложение на Python + Streamlit для предоставленного датасета из 66 профилей.

## Запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
streamlit run app.py
```

CSV уже находится в папке проекта. Приложение также автоматически проверяет:

`C:\Users\admin\Downloads\hackathon dataset anonymized .csv`

и вариант имени без пробела перед `.csv`. Другой CSV можно загрузить прямо через sidebar.

## Что реализовано

- город, дата, тип мероприятия, категория, бюджет;
- опционально длительность и язык;
- строгая проверка `busy_dates`;
- бюджет `price_from_kzt <= budget`;
- проверка `event_formats`, `languages`, `max_hours`;
- составные категории через `|`;
- до 3 карточек;
- индивидуальное объяснение каждой рекомендации;
- детерминированная сортировка;
- три разных состояния результата;
- объяснение пустой/неполной выдачи;
- маркировка исходных и `synthetic` профилей;
- отображение восстановленных `city_imputed` / `price_imputed`.

## Pipeline

1. **Candidate pool:** город + категория.
2. **Hard filters:** дата → бюджет → формат → язык → длительность.
3. **Ranking:** прозрачный score после hard-фильтров.
4. **Tie-break:** стабильный `id`, поэтому одинаковый запрос всегда имеет одинаковый порядок.
5. **Explanation:** факты о цене, формате, языке, длительности, тексте описания и свободной дате.

Score не решает, допустим ли подрядчик. Он только ранжирует уже допустимых кандидатов.

## Почему без обязательного LLM

Для 66 записей rule-based/hybrid pipeline быстрее, воспроизводимее и проще защищать перед жюри. Смысл описания используется как дополнительный keyword-based сигнал. Позже его можно заменить embeddings/LLM reranker, не меняя hard-фильтры.

## Демо для жюри

Покажите:
- плотную категорию: `Ведущий` или `Фотограф`;
- редкую: `Флорист`, `Декоратор`, `Подарки и сувениры`, `Ведущий церемонии`, `Фото и видеобудки` или `Инструменталист`;
- запрос с заведомо низким бюджетом либо неподходящим форматом;
- один запрос на двух разных датах, чтобы показать влияние `busy_dates`.

## Файлы

- `hackathon dataset anonymized .csv` — исходный датасет.
